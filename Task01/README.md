# Лабораторная работа 1. Структура файлов данных

Набор данных о фильмах, пользователях и их оценках.

## ratings.csv
Оценки фильмов пользователями. CSV, разделитель — запятая, первая строка — заголовок.

| Столбец   | Описание                          |
|-----------|-----------------------------------|
| userId    | идентификатор пользователя        |
| movieId   | идентификатор фильма              |
| rating    | оценка фильма (например, 4.0)     |
| timestamp | время оценки (Unix-время)         |

## movies.csv
Список фильмов. CSV, разделитель — запятая, первая строка — заголовок.

| Столбец | Описание                                      |
|---------|-----------------------------------------------|
| movieId | идентификатор фильма                          |
| title   | название фильма с годом выпуска в скобках     |
| genres  | жанры фильма, перечисленные через символ `\|` |

## tags.csv
Теги, которые пользователи присваивали фильмам. CSV, разделитель — запятая, первая строка — заголовок.

| Столбец   | Описание                           |
|-----------|------------------------------------|
| userId    | идентификатор пользователя         |
| movieId   | идентификатор фильма               |
| tag       | текст тега                         |
| timestamp | время добавления тега (Unix-время) |

## users.txt
Данные пользователей. Текстовый файл без заголовка, один пользователь в строке, разделитель полей — символ `|`.

| Поле | Описание                      |
|------|-------------------------------|
| 1    | идентификатор пользователя    |
| 2    | имя и фамилия                 |
| 3    | адрес электронной почты       |
| 4    | пол                           |
| 5    | дата регистрации (ГГГГ-ММ-ДД) |
| 6    | род занятий                   |

## genres.txt
Список жанров фильмов. Текстовый файл, один жанр в строке.

## occupation.txt
Список возможных занятий пользователей. Текстовый файл, одно значение в строке.

## Дополнительные файлы
- `ratings_count.txt` — минимальный и максимальный идентификатор пользователя в `ratings.csv` и количество оценок у каждого.
- `sqlite.txt` — версия SQLite и доступные режимы вывода утилиты sqlite3.
